Not safe: full scene synthesis, PF pattern decoding, resolved collision behavior, or a full renderer.

Block line / kernel phase ($FC)

 
temp3/blockLine/maxId triple alias at $FC. Kernel structure 12*2+8=32 from ASM comment. Phase labels are excerpt-constant-derived; kernel code NOT in excerpt.

 

 


 

 
Zero-const invariants ($F3/$F6)

 
zero1 ($F3) and zero2 ($F6) are declared "always zero!" in the ASM excerpt. Non-zero values indicate an inspector edit or write outside excerpt-grounded logic.

 

 


 

 
PF1PatId ($BC)

 
Playfield pattern ID for new generated block. Page boundary at SWITCH_PAGE_ID=9: ids < 9 = $FC, >= 9 = $FD. Generation code NOT in excerpt.

 

 


 

 
player1State byte area ($BD..$C1)

 
Declared player1State byte area with level alias byte, saved RNG pair, and livesPtr bytes. All sub-fields from excerpt ZP-VARIABLES. Read/write code NOT in excerpt.

 

 




 
Fuel Display State ($B7/$B8)

 
Unified fuel view: fuelHi ($B7), fuelLo ($B8), fuel16, ball position from MainLoop LDA/LSR/LSR/LSR/CLC/ADC#69. Drain/fill NOT in excerpt.

 






 
Player2 state ($C2..$C5)

 
player2State 4 bytes with livesPtr2=$C5 (low byte only, high is const). Read/write code NOT in excerpt -- inspector-only.

 






 
PF1PatId Page Boundary ($BC)

 
PF1 pattern ID page resolver. SWITCH_PAGE_ID=9: IDs >= 9 use ROM page $FD, others $FC. Zone labels are inspector-only aids. Generation code NOT in excerpt.

 






 
Block offset line ($B6 + $B9)

 
Computes section-relative line from blockOffset ($B6) and sectionBlock ($B9). (SECTION_BLOCKS - sectionBlock) * BLOCK_SIZE + blockOffset. Inspector-only; kernel scan order NOT in excerpt.

 






 
RNG seed period

 
LFSR period analysis for a given 16-bit seed. Seed $0000 = lock-up. Maximal period = 65,535. Section count (57,337) from ASM header. Cycle restriction logic NOT in excerpt.

 






 
Kernel timing ($FC)

 
Decodes blockLine/temp3 ($FC) into display phase (12x2-line = 24 scanlines) vs setup (8 lines). Structure from ASM header comment. Kernel code NOT in excerpt.

 






 
PF1 page address ($BC)

 
computePF1PageAddress: ROM page high byte from PF1PatId. < SWITCH_PAGE_ID(9) = $FC, >= 9 = $FD. Banking mechanism NOT in excerpt.

 






 
Section block sequence ($B9)

 
Enumerates raw sectionBlock countdown bytes: 0=transition sentinel, 1=bridge sentinel, 2..16=numbered block values. Derived from SECTION_BLOCKS=16 constant. Transition logic NOT in excerpt.

 






 
diffPF inspector ($F2)

 
The ASM excerpt declares "diffPF = temp ; difference between two PF pattern ids". The PF-difference computation itself is NOT in excerpt — this surfaces the raw byte only.

 






 
Block array end addresses

 
End-address constants from ASM excerpt: blockLstEnd ($93), XPos1LstEnd ($99), State1LstEnd ($9F), Shape1IdLstEnd ($A5), PF1LstEnd ($AB), PF2LstEnd ($B1). Derived as base+NUM_BLOCKS-1 for each of the six block arrays. Used by kernel to iterate blocks.

 






 
NUSIZ per slot ($9A..$9F)

 
TIA NUSIZx values decoded from State1Lst bit 0-2. ASM names: TWO_COPIES=%001, THREE_COPIES=%011, DOUBLE_SIZE=%101, QUAD_SIZE=%111 (ASM lines 158-162). Bit 3 = REFP1 direction. Fine-move bits 4-7 = HMxy. Full kernel NUSIZ write timing NOT in excerpt.

 






 
Section progress ($B9/$B6/$8B)

 
Section/block/offset progress inspector. sectionBlock ($B9, ASM line 217) counts down from SECTION_BLOCKS=16. blockOffset ($8B) advances per frame within BLOCK_SIZE=32. blockPart ($B6) toggles 1/2 for bridge halves. Section/block advance logic NOT in excerpt.
